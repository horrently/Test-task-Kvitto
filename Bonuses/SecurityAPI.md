# Проверка безопасности: что можно узнать или подделать через API


1) Попробовать подменить цену тарифа:

    **Проверка:** Передать в JSON дополнительные поля `price: 1` или `amount: 1`.

    **Ожидаемое поведение:** Сервер рассчитывает цену по тарифу, а не доверяет клиентской сумме.

    **Риск:** Оплата по неверной цене.

2) Подмена срока рассрочки	

    **Проверка:** `Передать installment_months: 1, 24` или строку вместо числа.

    **Ожидаемое поведение:** HTTP 422 для недопустимых значений.

    **Риск:** Неверный расчёт ежемесячного платежа.

3) Проверить можно ли получить данные чужого платежа.

4) Проверить можно ли подменить данные уже существующего платежа.
